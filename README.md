# Цэргийн эрх зүйн аман шалгалтын программ

React 18 + TypeScript + Tailwind CSS + Vite.

## Ажиллуулах

Node.js 18+ суулгасан компьютер дээр:

```bash
npm install
npm run dev
```

Терминалд гарсан `http://localhost:5173` хаягийг нээнэ.

## Боломжууд
- Аман шалгалт: асуулт харуулах, хариулт нээх/нуух
- A/B тест: эх баримт дахь заалтын агуулгыг хоёр сонголтоос таних
- Хуулиар шүүх, текстээр хайх, асуултуудыг холих
- Судалсан асуултыг браузерт хадгалах
- Асуултын сан, зөв хариултын хувь

## Өгөгдлийн эх сурвалж
`src/questions.json` — хэрэглэгчийн өгсөн `БҮХ АСУУЛТ ХАРИУЛТ аман шалгалт.docx` файлаас автоматаар задлан авсан асуулт, хариулт, хуулийн үндэслэл. Тухайн Word файлд хариултын хэсэг дутуу эсвэл хураангуй байвал программ мөн адил харуулна. Албан ёсны хууль тогтоомжийн баталгаажсан сан биш.

## Бүтээх
`npm run build` команд нь `dist/` хавтас үүсгэнэ. Netlify/Vercel дээр build command `npm run build`, publish directory `dist` гэж тохируулна.


## Өнгө ба гар утас
Өнгө: #1B365D, #005A9C, #60C1E5, #A0E0EF. Responsive layout, touch controls, mobile viewport тохиргоотой.

Гар утсаар нэг Wi-Fi сүлжээнд ашиглах: компьютерт `npm run dev -- --host 0.0.0.0` ажиллуулаад терминалын Network URL (`http://<computer-ip>:5173`) рүү утаснаасаа орно. Интернэтээр хаанаас ч нэвтрэх бол тусад нь hosting-д байршуулна.

Pinterest хайлтын холбоосоос sticker файлыг шууд татаж авч ашиглаагүй. Зохиогчийн эрх болон тухайн зургийн файл тодорхой болсны дараа тохирох sticker-ийг нэмэх боломжтой.

## Утсаар ашиглах

GitHub репозиторийн main салбарт төслийг байрлуулаад Settings → Pages → Source → GitHub Actions сонгоно. Actions → GitHub Pages → Run workflow дарна. Нийтэлсний дараа Pages-ийн холбоосыг утаснаасаа нээнэ.

Дотоод сүлжээнд турших бол npm ci, дараа нь npm run dev ажиллуулж, Vite-ийн Network холбоосыг ижил Wi-Fi-д холбогдсон утсаар нээнэ.

## Асуулт нэмэх

«Асуулт, хариулт нэмэх» хэсэгт сэдэв, асуулт, хариултаа бичээд хадгална. Энэ өөрчлөлт тухайн хөтөч дээр хадгалагдана. Бүх хэрэглэгчид шинэ асуулт өгөхдөө src/questions.json-д мөр нэмж, давтагдашгүй id оноогоод main салбар руу илгээнэ.
